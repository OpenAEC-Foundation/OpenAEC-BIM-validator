Server-Side IFC Rendering

This POC demonstrates server-side IFC processing with browser-based display of optimized geometry.

Browser → Upload IFC → Server Process → Optimized Geo → Render

What happens when you load a file:

  • File is uploaded to the server (FastAPI)
  • Server parses IFC using ifcopenshell
  • Geometry is extracted and optimized
  • glTF or JSON mesh is sent to browser
  • Three.js renders the optimized geometry
